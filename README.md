# Car Price Prediction - CodeAlpha Data Science Internship

A comprehensive machine learning regression project designed to predict car prices based on key vehicle features, developed as part of the CodeAlpha Data Science Internship.

## 📌 Project Overview
Estimating the fair market value of a used car can be challenging due to multiple factors like brand, age, mileage, fuel type, transmission, and condition. This project builds and evaluates supervised machine learning models to forecast car prices accurately using regression techniques.

## Key Features & Workflow
- **Data Cleaning & Feature Engineering:** Handling missing values, encoding categorical variables, scaling numeric features, and extracting valuable insights.
- **Exploratory Data Analysis (EDA):** Visualizing feature correlations, price distributions, and trends across brands and manufacturing years.
- **Model Building & Evaluation:** Training regression algorithms (Linear Regression, Decision Tree, Random Forest, etc.) and evaluating performance using Metrics like $R^2$ Score, MAE, and RMSE.

## Tech Stack
- **Language:** Python
- **Data Analysis & Visualization:** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn
- **Environment:** Kaggle Notebook
